## Summary
DONE: Sentinel address resolution added to AddressTable.

### Changes Applied
- Added sentinel constants: SENTINEL_PM (0xFC), SENTINEL_SELF (0xFD), SENTINEL_WETH (0xFE), SENTINEL_NATIVE (0xFF), SENTINEL_USER0 (0xF0), SENTINEL_USER1 (0xF1), SENTINEL_THRESHOLD (0xF0)
- AddressTable now accepts kwargs: weth_address, executor_address, pool_manager_address, user0_address, user1_address
- NATIVE_ADDRESS and ZERO_ADDRESS always map to SENTINEL_NATIVE (0xFF)
- `add()` checks sentinels first, returning fixed index without table insertion
- `index_of()` checks sentinels
- `__contains__` checks sentinels
- `addresses` property returns only table addresses (excludes sentinels) — enc_set_addresses() naturally skips sentinels
- Table indices limited to 0x00-0xEF (240 max) with assertion
- Updated eth_backrun_helpers.py: all AddressTable() calls now use sentinel parameters
- Replaced `zero_idx = at.add(CMD_ZERO_ADDRESS)` with `zero_idx = SENTINEL_NATIVE`
