## Summary
The new cmd_executor uses sentinel address indices (0xF0–0xFF) that resolve to common addresses without SET_ADDRESS or TLOAD. This saves ~476 gas per sentinel use and eliminates SET_ADDRESS calldata bytes. The AddressTable must detect and return sentinel indices for known addresses.

## Sentinel Mapping (from user-guide.md §6 / Appendix B)

| Index | Name | Resolves To | Typical Mainnet Value |
|-------|------|-------------|-----------------------|
| `0xFC` | V4_PM_SENTINEL | PoolManager (immutable) | `0x000000000004444c5dc75cB358380D2e3De08A90` |
| `0xFD` | V4_SELF_SENTINEL | `self` (executor) | executor address |
| `0xFE` | V4_WETH_SENTINEL | WETH (immutable) | `0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2` |
| `0xFF` | V4_NATIVE_SENTINEL | `address(0)` | NATIVE_ADDRESS |
| `0xF0` | V4_USER0_SENTINEL | USER0 (deploy-time) | USDC `0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48` |
| `0xF1` | V4_USER1_SENTINEL | USER1 (deploy-time) | WBTC `0x2260FAC5E5542a773Aa44fBCfeDf7C193bc2C599` |

Additionally, `hooks_idx = 0xFF` means "no hooks" — eliminates SET_ADDRESS for ZERO_ADDRESS in every V4 swap.

## Changes to AddressTable

```python
class AddressTable:
    def __init__(
        self,
        *,
        weth_address: str | None = None,
        executor_address: str | None = None,
        pool_manager_address: str | None = None,
        user0_address: str | None = None,  # Typically USDC
        user1_address: str | None = None,  # Typically WBTC
    ):
        self._sentinel_map: dict[ChecksumAddress, int] = {}
        # Register sentinels for known addresses
        if pool_manager_address:
            self._sentinel_map[to_checksum_address(pool_manager_address)] = 0xFC
        if executor_address:
            self._sentinel_map[to_checksum_address(executor_address)] = 0xFD
        if weth_address:
            self._sentinel_map[to_checksum_address(weth_address)] = 0xFE
        # NATIVE_ADDRESS always maps to 0xFF
        self._sentinel_map[NATIVE_ADDRESS] = 0xFF
        if user0_address:
            self._sentinel_map[to_checksum_address(user0_address)] = 0xF0
        if user1_address:
            self._sentinel_map[to_checksum_address(user1_address)] = 0xF1

    def add(self, addr: str | ChecksumAddress) -> int:
        # Check sentinel first
        if addr in self._sentinel_map:
            return self._sentinel_map[addr]
        # ... existing table logic (indices 0x00–0xEF only)
```

## Benefits
- Eliminates SET_ADDRESS commands for 6 most common addresses
- Eliminates TLOAD for sentinel lookups (precomputed delta slots)
- "No hooks" (0xFF) eliminates SET_ADDRESS for ZERO_ADDRESS in every V4 swap
- Calldata savings: ~21 bytes per eliminated SET_ADDRESS + reduced table size

## Implementation Notes
- Table indices 0x00–0xEF remain for pool-specific addresses (240 max, more than enough)
- `enc_preamble()` must skip SET_ADDRESS for sentinel addresses
- The no-hooks sentinel (0xFF for hooks_idx) is distinct from the NATIVE_ADDRESS sentinel (0xFF for address resolution) — same byte value, different context
- All path encoders in eth_backrun_helpers.py should pass sentinel-configured AddressTable
