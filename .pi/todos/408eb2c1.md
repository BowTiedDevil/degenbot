**Slice 10 of the Polars three-layer migration (ADR-005, deferred target).** Master: `TODO-7e24d695`. Deps: slice 9 (V4 companion; engine path understood). **Closes open TODO `9356aaf7`** ("Eliminate Python pool mutable state for engine-managed pools").

**Goal.** Unify `UniswapEngine` onto the SAME `Arc<RwLock<Bot>>` as `PyBot` — one Rust-owned `Bot`, the engine pump + Python companions both read/write through it. Eliminates dual-state for engine-managed pools: the Python companion now reads LIVE engine-updated state (`9356aaf7`'s payoff).

**Rust.**
- `UniswapEngine.core: Arc<Mutex<Bot>>` → `Arc<RwLock<Bot>>` shared with `PyBot`.
- Resolve the nested lock-ordering question (ADR-005 Deferred): engine-then-core currently `Mutex`-then-`Mutex`; collapsing to one shared core lock, OR a documented alternative discipline. Lock order when nested stays engine-then-core; Python-facing `PyBot` methods take core alone and never call into the engine (the rule keeping the deadlock surface empty — ADR-003).
- `PyUniswapArbEngine` constructed WITH the shared `Arc`: needs a `PyBot` method to hand out the underlying `Arc` (or the engine is constructed FROM the `PyBot`/`Bot`).
- Spawned pump writes to the shared `Bot`; Python companions read live.

**Python.** `Bot` constructs the shared `PyBot` and passes the `Arc`/handle to `UniswapArbEngine`; Python subscribes to `newHeads` for fee/nonce only; results read from the engine channel.

**Tests.** `9356aaf7` acceptance; backrun-path tests (pump updates → companion reads live state, no stale reads); lock-deadlock surface tests; concurrent reader/writer tests under free-threading assumptions.

**Consistency at boundary.** Engine-managed pools' companions read live state (dual-state eliminated). `UniswapArbEngine` backrun path stays green. **RISKIEST slice** (lock semantics across the engine + Python) — execute with red/green TDD around the deadlock surface; do not collapse without characterizing the current engine-then-core `Mutex` invariant first.

**Acceptance.** `cargo`/`ruff`/`ty` green; `9356aaf7` closed; backrun-path tests + companion-live-read tests pass; no deadlock regressions (stress test the pump+read interleaving).
