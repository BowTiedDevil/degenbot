## Status: Encoders work, intermittent due to state drift

V3-V2 `TF` failures are intermittent — the encoder pattern matches the verified test from `test_cmd_executor_v2v3.py::TestV3ToV2`. The `TF` occurs when V2's actual WETH output differs from the solver's prediction due to pool state drift between the solve block and simulate block. The executor transfers `optimal_input` WETH to V3, but V2 only provided `weth_out` which may be less than `optimal_input` if the on-chain state changed.

This is an inherent limitation of the solve-then-simulate architecture, not an encoder bug. The V3-V2 encoder is working correctly.
