**Slice 7 of the Polars three-layer migration (ADR-005).** Master: `TODO-7e24d695`. Deps: slice 4, 5 (V2 companion fully delegates), slice 6 (`DexIdentity`).

**Goal.** Collapse the hollow DEX-class hierarchy (stance B) into the generalized `LiquidityPool` companion carrying `dex: DexIdentity` data + strategy mixins for the two genuine behavioral DEXes (Camelot solidly-stable calc, Aerodrome log decoder). `Bot.build_pool` returns `LiquidityPool`. **Public API break — accepted (0.x major refactor, user-confirmed).** No back-compat layer per AGENTS.md.

**Design decision (slice-7).** Builder resolves `DexIdentity` preset → unfolded `register_v2_pool` params (keeps `PyBot.register_v2_pool` signature stable). Strategy behavior keyed on `dex.variant`. Per-DEX strategy objects (`CamelotPoolCalc` solidly-stable, Aerodrome `_decode_aerodrome_v2_sync` decoder) wire the pre-wired `_calc_tokens_out_fn` / log handler from `DexVariant`.

**Python.**
- NEW generalized `LiquidityPool` companion (rename of `UniswapV2Pool` or new class) wrapping `PyLiquidityPool` + `dex: DexIdentity`.
- Strategy mixins: `CamelotPoolCalc` (solidly-stable) + Aerodrome decoder become strategy objects keyed on `dex.variant`.
- DELETE `SushiswapV2Pool`, `PancakeswapV2Pool`, `SwapbasedV2Pool`, `CamelotLiquidityPool`, `AerodromeV2Pool` (no back-compat aliases per AGENTS.md "design standalone features without a backwards compatibility layer"). Their tests become `LiquidityPool` + preset tests.

**Builders / Pool Type Registry.** `V2PoolBuilder` (+ collapsed `AerodromeV2Builder`/`CamelotBuilder`) resolves `DexIdentity` preset from factory (Pool Type Registry maps `(chain_id, factory) → DexIdentity`/`DexVariant`, not `→ class`) + constructs `LiquidityPool` with the right strategy. Per-DEX self-registration (`pool_type_registry.register()`) updates from class→identity.

**Registries.** `PoolRegistry` stores `LiquidityPool`. `Bot.build_pool` returns `LiquidityPool` for all V2-family.

**Tests.** Rewrite DEX-subclass tests as `LiquidityPool` + preset tests. Camelot stable / Aerodrome stable behavior tests stay (via strategy). V2 calc tests stay (unchanged).

**Consistency at boundary.** BREAKING — callers doing `isinstance(pool, SushiswapV2Pool)` break (documented; 0.x). `Bot.build_pool` returns `LiquidityPool` for all V2-family. Camelot/Aerodrome stable calc behavior preserved via strategy. All V2-family tests pass.

**Acceptance.** `cargo`/`ruff`/`ty` green; DEX-subclass tests rewritten + pass; Camelot/Aerodrome stable strategy tests pass; `Bot.build_pool` returns `LiquidityPool`; `isinstance` calls audited + breaking change documented in a migration guide.

**V2PoolBuilder** (`src/degenbot/builders/v2_pool_builder.py`): `dex = pool_type_registry.get_v2_identity(chain_id, common.factory)` alongside the existing `get_v2_class`; passes `dex=dex` to the companion. ### Design notes for step 4

- The `dex.fee_token0 = (gamma_numer, fee_denom)` ↔ Python `fee_token0: Fraction` conversion is encapsulated in `LiquidityPool.__init__` + `make_v2_pool`. When step 4 deletes the subclasses, the builders + tests that today pass explicit `fee_token0=Fraction(...)` can switch to `dex=preset` + omit the fee (the preset provides it). The conversion stays at the `LiquidityPool` boundary.
