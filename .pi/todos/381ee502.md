## Bug
The `cmd_executor_runtime_bytecode.txt` had wrong immutable values:
- The POOL_MANAGER_ADDR (slot 3) was zero address — all V4 paths reverted at ~38K gas with empty revert data
- Initial patch incorrectly assumed slot order was [PM, WETH, OWNER], overwrote OWNER slot with PM address → caused `!OWNER` revert on all paths
- Correct order (matching Vyper declaration): **[OWNER_ADDR, WETH_ADDR, POOL_MANAGER_ADDR]**

## Fix
1. Restored original bytecode from git
2. Patched only slot 3 (POOL_MANAGER_ADDR) with `0x000000000004444c5dc75cB358380D2e3De08A90`
3. Updated contracts/README.md with correct slot order, critical warning, and patching instructions
