## Root Causes & Fixes

All root causes are in the Python encoder (`examples/eth_backrun_helpers.py`), not the executor contract (all 27 contract tests pass).

### Bug 1: `_3hop_v4_v3_v3` — `CurrencyNotSettled()` ✅ FIXED
- **Cause**: Used `sync + transfer(optimal_input) + settle()` for WETH. V4 rounding can make the actual delta differ from `optimal_input` by ±1 wei.
- **Fix**: Replaced with `enc_v4_settle_delta(weth_idx)` which reads the exact delta.

### Bug 2: `_3hop_v4_v4_v4` — `CurrencyNotSettled()` ✅ FIXED
- **Cause**: No settlement command after 3 V4 swaps + profit take.
- **Fix**: Added `enc_v4_settle_delta(weth_idx)`.

### Bug 3: `_3hop_v4_v4_v3` — `IIA` ✅ FIXED
- **Cause**: `forward_b_idx` used `currency0 if currency0 != weth else currency1`. For V4b with two non-WETH currencies and `zfo=True`, this picked the INPUT instead of OUTPUT.
- **Fix**: Changed to `currency1 if hb.zfo else currency0`.

### Bug 4: Same heuristic in 12 locations ✅ FIXED
- All 12 occurrences replaced with zfo-aware output currency.
- Affected: `_3hop_v2_v4_v2`, `_3hop_v2_v4_v3`, `_3hop_v3_v4_v2`, `_3hop_v3_v4_v3`, `_3hop_v4_v2_v2`, `_3hop_v4_v2_v3`, `_3hop_v4_v2_v4`, `_3hop_v4_v3_v2`, `_3hop_v4_v3_v3`, `_3hop_v4_v3_v4`, `_3hop_v4_v4_v2`, `_3hop_v4_v4_v3`.
