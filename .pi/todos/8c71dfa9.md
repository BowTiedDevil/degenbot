## Summary
DONE: All encoding sizes in cmd_stream.py updated to match the new cmd_executor contract.

### Changes Applied
- Amount fields: uint128 (16 bytes) → uint96 (12 bytes) across all encoders
- V4 fee: 3 bytes → 2 bytes (uint16)
- V4 tick_spacing: 3 bytes → 2 bytes (int16 encoded as unsigned)
- Forward-data length: 2 bytes → 1 byte (max 255 bytes)
- ERC20_TRANSFER amount: 32 bytes → 12 bytes (15 bytes total vs 35)
- SEND_ETH amount: 16 bytes → 12 bytes (14 bytes total vs 18)
- Parameter name: `amount_u128` → `amount_u96` in all V4 functions
- Added `pack_expected_balance()` helper for (value<<8)|mode format
- Added `enc_bribe_coinbase()` and `enc_bribe_address()` helpers
- Updated `enc_preamble()` with bribe support
- Added V4_BATCH assert for max 8 swaps
