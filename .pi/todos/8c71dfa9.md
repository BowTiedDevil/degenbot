## Summary
The cmd_stream.py encoding module uses byte sizes that don't match the new cmd_executor contract. Amounts use uint256/uint128 (32/16 bytes) instead of uint96 (12 bytes), V4 fee uses 3 bytes instead of 2, V4 tick_spacing uses 3 bytes instead of 2, and forward_data length uses 2 bytes instead of 1. EVERY encoding function that talks to the new contract must be updated.

## Specific Changes (cmd_stream.py)

### Amount fields: uint128/uint256 → uint96 (12 bytes)
- `enc_v2_swap_compact`: `_e(amount_out, 16)` → `_e(amount_out, 12)` 
- `enc_v2_swap_direct`: `_e(amount_out, 16)` → `_e(amount_out, 12)`
- `enc_v3_swap_compact`: `_e(amount_specified, 16)` → `_e(amount_specified, 12)`
- `enc_v4_swap_compact`: `_e(amount_u128, 16)` → `_e(amount_u128, 12)`
- `enc_v4_take_compact`: `_e(amount_u128, 16)` → `_e(amount_u128, 12)`
- `enc_v4_mint_compact`: `_e(amount_u128, 16)` → `_e(amount_u128, 12)`
- `enc_v4_burn_compact`: `_e(amount_u128, 16)` → `_e(amount_u128, 12)`
- `enc_v4_batch` entries: amount 16 → 12 bytes (entry shrinks from 26 → 20 bytes)
- `enc_send_eth`: `_e(amount, 16)` → `_e(amount, 12)`

### V4 fee: 3 bytes → 2 bytes
- `enc_v4_swap_compact`: `_e(fee, 3)` → `_e(fee, 2)`
- `enc_v4_swap_dynamic`: `_e(fee, 3)` → `_e(fee, 2)`
- `enc_v4_batch` entries: fee 3 → 2 bytes

### V4 tick_spacing: 3 bytes → 2 bytes (int16, encoded as unsigned)
- `enc_v4_swap_compact`: `_e(tick_spacing, 3, signed=True)` → `_e(tick_spacing, 2, signed=True)` 
- `enc_v4_swap_dynamic`: same
- `enc_v4_batch` entries: same

### Forward-data length: 2 bytes → 1 byte
- `enc_v2_swap_compact`: `_e(len(forward_data), 2)` → `_e(len(forward_data), 1)` (max 255 bytes)
- `enc_v3_swap_compact`: `_e(len(forward_data), 2)` → `_e(len(forward_data), 1)`
- `enc_v4_unlock`: `_e(len(forward_data), 2)` → `_e(len(forward_data), 1)`

### Updated command sizes (for reference)
| Command | Old Size | New Size | Delta |
|---------|----------|----------|-------|
| V2_SWAP_COMPACT base | 24+N | 19+N | -5 |
| V2_SWAP_DIRECT | 20 | 16 | -4 |
| V3_SWAP_COMPACT base | 22+N | 17+N | -5 |
| V4_SWAP_COMPACT | 27 | 21 | -6 |
| V4_SWAP_DYNAMIC | 11 | 9 | -2 |
| V4_BATCH per entry | 26 | 20 | -6 |
| V4_TAKE_COMPACT | 19 | 15 | -4 |
| V4_MINT_COMPACT | 19 | 15 | -4 |
| V4_BURN_COMPACT | 18 | 14 | -4 |
