PyO3 0.29 adds PEP 803 `abi3t` ABI support via new `abi3t` and `abi3t-py315` features. This targets a "truly stable" subset of the limited API that could produce smaller, more portable wheels.

Current: `abi3-py312` feature. Evaluate whether `abi3t` could replace or supplement it for wheel distribution. Check:
1. What APIs are available under `abi3t` vs `abi3-py312`
2. Whether our code uses any non-abi3t-compatible APIs
3. Whether maturin supports `abi3t` wheel tags yet

This is an optimization, not a blocker.
