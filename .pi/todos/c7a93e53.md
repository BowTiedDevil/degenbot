Per AGENTS.md: "Free-threaded Python 3.14+: `RefCell` is unsafe; use `Mutex` for interior mutability." PyO3 0.29 adds `PyClassGuard` / `PyClassGuardMut` to the prelude — the free-threaded-safe replacement for `PyRef<T>`.

9 call sites to migrate:
- `rust/src/optimizers/mobius_py.rs` — 7 uses (`PyRef<PyV3TickRangeHop>`, `PyRef<PyIntHopState>`, `PyRef<PyHopState>`, `PyRef<PyV3TickRangeSequence>`)
- `rust/src/optimizers/uniswap_engine/py_binding.rs` — 1 use in `__aiter__`
- `rust/src/subscription_py.rs` — 1 use in `__aiter__`

This is not urgent for GIL-based operation but is required for free-threaded Python 3.14+ support.
