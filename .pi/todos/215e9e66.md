**Settled design (recorded in ADR-006 + `rust/CONTEXT.md`).**
- **D1:** one shared `Arc<RwLock<Bot>>`; `PyBot` and engine adopt a clone via `with_core`/`from_core`; `new()` kept as standalone sugar for no-pyo3 tests.
- **D2:** `RwLock` on the shared core; engine keeps its own `Mutex<UniswapEngine>`; lock order engine-then-core unchanged; ~30 `self.core.lock()` → `read`/`write`.
- **D3:** delete engine `register_v2/v3/v4_pool`; pool construction is a `Bot` concern only; engine intake = `register_path` resolving `pool_id`s against the associated `Bot`.
- **D4:** `Bot` is the per-chain orchestrator (owns RPC + `chain_id` + pump + `Vec<Box<dyn EventSink>>`); a thin deep interface over cohesive `pub(crate)` helpers; standalone-Rust = full Polars split-UX (a Rust user runs the whole bot, no Python).
- **D5:** one `Bot` per chain; multi-chain = N Bots; `bot.py` becomes a single-chain facade (un-wind the swallowed multi-chain managers).

**Cohesive helper decomposition (D4, each `pub(crate)`, own test seam):**
`Bot` (thin interface: `new`/`attach_engine`/`register_pool`/`start`) → `BotState` (today's pure-data `Bot`), `LogDispatcher` (decoder registry + `Weak<dyn StateSubscriber>` notifier), `BlockPump` (WS transport + drain loop, today's `uniswap_engine_prop.rs` generalized), `SolveCoordinator` (drain-point solve tick; `SolvePolicy` enum deferred), `ReorgCoordinator` (restore).

**Resolved sub-decisions:** event bus = per-pool subscriber notify after core-write release (engine dirties own set, solves at drain = coalesced α, D2 order preserved); notify payload = bare `pool_id` (shape (i)); reorg = optimistic per-event `restore_before_block(B)` per `removed: true` log, no separate `on_reorg` method (WS replay ordering unspecified → `restore_before_block` idempotency handles any order).

**Definitely deferred (recorded, don't re-derive):** `SolvePolicy` enum (one consumer short of seam bar; composes on top of drain; distinct from `EnginePhase`); `AaveLiquidationEngine` (proof-of-seam second strategy); candidate-2 file relocations absorbed into S3-S7; crate split (`TODO-41b7b22e`) stays ADR-005-deferred.
