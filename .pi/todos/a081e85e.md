## Resolution

Fixed V3-V4 encoder — replaced hardcoded `V4_TAKE_DELTA(weth_idx)` with `V4_TAKE(output_idx, executor, weth_out)` using the correct V4 output currency index:
- `zfo=True` → output is currency1 → `c1_v4_idx`
- `zfo=False` → output is currency0 → `c0_v4_idx`

This resolves `V4_TAKE_DELTA: non-positive delta` which occurred when the hardcoded `weth_idx` pointed to a currency with a negative delta (we owe PM, not the other way around).
