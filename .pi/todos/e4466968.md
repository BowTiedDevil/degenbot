COMPLETED. Changes:

uniswap_engine_pump.rs:
- Added `EventType` enum (SYNC, SWAP, MINT, BURN) for configurable buffer inclusion set
- Added `DEFAULT_BUFFER_EVENTS` constant: [MINT, BURN]
- Added `topic_matches_event_type()` helper to check if a topic matches the inclusion set
- Added `SubscribeState` struct with `first_block`, `first_timestamp`, `combined_stream` fields
- Added `subscribe()` async method: opens WS, runs subscribe phase buffering MINT/BURN events into engine's liquidity event buffers, returns first observed block number
- Added `subscribe_phase()` method: loops until first block header, routing matching events to engine buffers
- Added `buffer_subscribe_log()` method: routes V3 Mint/Burn and V4 ModifyLiquidity events to sub-engine buffers during subscribe
- Added `resume_from_subscribe()` and `resume()` methods: transition to normal pump processing
- Added `run_with_stream()` method: core event loop shared between resume paths, takes existing stream + first_observed_block
- Added `take_block_rx()` method: for PyO3 to get the watch receiver
- Made `WsEvent`, `filter_relevant_logs`, `RELEVANT_TOPICS` public for PyO3 access
- Removed old `run()` method (replaced by `run_with_stream`)
- Updated `stream_select` to return `BoxStream` for storage in `SubscribeState`
- Legacy `spawn()` path works via subscribe + resume internally
- 3 new unit tests for `topic_matches_event_type`

uniswap_engine.rs (PyO3):
- Added `subscribe_state: Mutex<Option<PySubscribeState>>` field to `PyUniswapArbEngine`
- Added `PySubscribeState` struct holding pump, first_block, combined_stream
- Added `subscribe(rpc_url, buffer_event_types=None)` PyO3 method: runs async subscribe synchronously, returns first observed block number
- Added `resume()` PyO3 method: spawns resume task with stored pump and stream
- Both methods validate state transitions (can't subscribe twice, can't resume without subscribe)
- 3 new Python tests for subscribe/resume API
