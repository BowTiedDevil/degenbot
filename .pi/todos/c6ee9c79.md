## Fix Applied

V3-V3 encoder rewritten to forward-order matching the verified test pattern from `test_cmd_executor_v2v2_v3v3.py::TestV3V3`:

```
V3_A.swap(forward_data = ERC20_TRANSFER(WETH→V3_A) + V3_B.swap(autopay))
```

Key insight: **V3 transfers output BEFORE callback** (same as V2). The executor has the forward token during V3_A's callback, enabling V3_B's auto-pay. The executor needs reserve WETH (from stateDiff) to explicitly pay V3_A.
