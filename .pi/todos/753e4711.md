PyO3 0.29 was released 2026-06-11. `pyo3` and `pyo3-async-runtimes` are version-locked and must be bumped together. Current pins in `rust/Cargo.toml`:

```toml
pyo3 = { version = "^0.28", features = [ "abi3-py312", "serde"] }
pyo3-async-runtimes = { version = "^0.28", features = ["tokio-runtime"] }
```

Change both to `^0.29`. After bumping, run `just test-rust` and `just test-rust-python` to verify.
