**Slice 13 of the Polars three-layer migration (ADR-005, deferred target).** Master: `TODO-7e24d695`. Deps: slices 3-12 (all companions done; the `*_py.rs` PyO3 surface is stable).

**Goal.** Split the single `rust/` crate into three, mirroring Polars exactly (`polars-core` / `polars-python` / `polars` umbrella):
- `degenbot-core` — `Bot`, `V2/V3/V4/Curve/BalancerPoolState`, `DexIdentity` + presets, calc math, reorg, event decoders. **Zero `pyo3` imports** (verified like Polars: `rg 'use pyo3' degenbot-core/src` = empty; the `polars-core` precedent found a declared-but-unused `pyo3` dep with 0 imports — degenbot-core must have neither).
- `degenbot-python` (name TBD) — all `*_py.rs` `#[pyclass]`/`#[pyfunction]` files: `py_bot.rs`, `py_liquidity_pool.rs`, `py_erc20_token.rs`, `py_binding.rs` (PyUniswapArbEngine), etc. All `pyo3` lives here.
- `degenbot` (umbrella Python package) — the Python `Bot` companion + the `degenbot_rs` extension built from `degenbot-python`. Rust consumers `cargo add degenbot` (umbrella) which `pub use`s core types with zero `pyo3`.

**Rust.** `Cargo.toml` workspace split; `rg 'use pyo3'` for every `*.rs` — pure-core files move to `degenbot-core`, `*_py.rs` files move to `degenbot-python`; cross-crate `pub use` re-exports preserve import paths. `DexIdentity` (slice 6) is already Rust-side — no stranding (the whole point of the land-Rust-first discipline).

**Tests.** A standalone-Rust-consumer smoke test: a small Rust binary/example that `cargo add degenbot-core`, constructs a `Bot`, registers a V2 pool via a `DexIdentity` preset (`UNISWAP_V2`), and runs a calc — **with no Python in the build**. This is the ADR-005 standalone claim made concrete.

**Consistency at boundary.** Python extension still builds + imports (`degenbot_rs` built from `degenbot-python`). All existing Python + Rust tests pass. Import paths via `pub use` unchanged. No `pyo3` leak into `degenbot-core`.

**Acceptance.** `cargo`/`ruff`/`ty` green; standalone `degenbot-core` consumer test runs without Python; `rg 'use pyo3' degenbot-core/src` = empty; `degenbot_rs` import probe + full test suite green; `cargo add degenbot` umbrella re-exports `Bot`/`DexIdentity`/state structs with zero `pyo3`.
