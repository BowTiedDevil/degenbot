## Summary
DONE: V4_BATCH for V4→V4 paths.

### Changes Applied
- `encode_cmd_stream()` now accepts `use_v4_batch: bool = False` kwarg
- V4→V4 2-hop: V4_BATCH replaces V4_SWAP_COMPACT + V4_SWAP_DYNAMIC. Saves ~5K gas from single PM extcall. Uses 42 bytes vs 34 bytes calldata — slightly more bytes but significant gas savings.
- V4→V4→V4 3-hop: V4_BATCH replaces 3 individual V4 swap commands (62 bytes vs 40 bytes). Auto-settles WETH + native ETH deltas.
- V4_BATCH only applies to same-currency paths (no wrap/unwrap). Wrap/unwrap paths still use individual commands because tokens must leave PM.
- V4_BATCH auto-settles eliminates the need for V4_TAKE_DELTA + V4_SETTLE_ALL for WETH/native ETH profit currencies.
- For ERC-20 profit currencies (not auto-settled by V4_BATCH), explicit V4_TAKE_DELTA is still needed.
