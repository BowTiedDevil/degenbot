Add configurable staleness limit for the Mint/Burn event buffer:

- **Default**: unbounded (no automatic expiry)
- **Construction time**: parameter on `V3BlockEngine::new()` / `V4BlockEngine::new()` / `UniswapEngine::new()` setting max buffer age in blocks
- **Runtime**: method to change the limit (e.g. `set_event_buffer_max_age(blocks: u64)`)
- **Flush**: method to discard all buffered events (e.g. `flush_event_buffer()` or `discard_buffered_events()`)

Expiry removes events older than `current_block - max_age`. Triggered during `process_block` or lazily on next claim attempt.

**Decisions**:
- Default unbounded
- Construction-time parameter
- Runtime adjustment method
- Explicit flush method
- Expiry checked during `process_block`
