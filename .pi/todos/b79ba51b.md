COMPLETED. Changes:

V3BlockEngine:
- Added `event_buffer_max_age: Option&lt;u64&gt;` field
- `new_with_buffer_max_age(Option&lt;u64&gt;)` constructor
- `set_event_buffer_max_age(Option&lt;u64&gt;)` runtime method
- `flush_event_buffer()` discards all buffered events
- `expire_buffered_events(current_block)` removes events older than cutoff, called from `process_block`
- Added 3 tests: max_age expires old events, flush discards all, set updates limit

V4BlockEngine:
- Same fields and methods as V3
- `expire_buffered_events` called from `process_block`
- Added 2 tests: max_age expires old events, flush discards all

UniswapEngine:
- `new_with_buffer_max_age(Option&lt;u64&gt;)` delegates to V3/V4 sub-engines
- `set_event_buffer_max_age(Option&lt;u64&gt;)` delegates to both
- `flush_event_buffer()` delegates to both

PyO3:
- `set_event_buffer_max_age(max_age: Optional[int])` 
- `flush_event_buffer()`
- Added Python TestEventBufferControl class
