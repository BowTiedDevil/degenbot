## Completed

Extracted shared tick-update helpers from V3/V4 block engines into `bot_core/tick_bitmap.rs`, following the TODO's recommendation to extract shared patterns instead of attempting a full generic collapse.

### Extracted components

1. **`update_tick_liquidity`** — Moved from `optimizers/v3_block_engine.rs` and `optimizers/v4_block_engine.rs` to `bot_core/tick_bitmap.rs`. This is the canonical Uniswap V3 `Tick.update()` implementation. Added `S: BuildHasher` generic to satisfy clippy.

2. **`apply_liquidity_to_tick_range`** — New helper that composes the standard Mint/Burn/ModifyLiquidity pattern: update lower tick, update upper tick, then `retain` ticks with zero `liquidity_gross`. Replaced 11 call sites across both engines.

### Lines of code impact

- `+67` lines in `bot_core/tick_bitmap.rs` (shared functions)
- `−78` lines in `v3_block_engine.rs` (removed duplicate function + simplified call sites)
- `−103` lines in `v4_block_engine.rs` (removed duplicate function + simplified call sites)
- **Net: −114 lines** of duplicated code eliminated
