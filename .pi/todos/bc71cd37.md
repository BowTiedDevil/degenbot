**Slice 8 of the Polars three-layer migration (ADR-005).** Master: `TODO-7e24d695`. Deps: slice 4 (companion pattern proven on V2). Independent of slice 7 (V3 has no DEX subclasses to collapse).

**Goal.** Make `UniswapV3Pool` a companion over `PyLiquidityPool` (V3 variant): scalar state (sqrt_price/liquidity/tick) + tick data reads delegate to Rust; `external_update` (Swap/Mint/Burn) delegates to `PyBot.update_v3_pool` + the liquidity-update path; reorg journal via `PyBot.v3_*` methods. Calc delegates to `PyLiquidityPool.calculate_tokens_out/in` (Rust `v3_simulate_swap`).

**Rust.**
- ADD V3 read getters to `PyLiquidityPool`: `sqrt_price_x96`, `liquidity`, `tick` (dispatch by variant on `Bot::get_v3_pool`).
- `PyBot.update_v3_pool` exists but is scalar-only (empty tick vec). VERIFY + extend the Mint/Burn liquidity-update path: expose `apply_v3_liquidity_update`/mint-burn application through `PyBot` (mirror `update_v3_pool` signature + a tick-delta path) so the companion's `external_update` for Mint/Burn reaches Rust. `v3_journal_len`/`v3_discard_before_block`/`v3_restore_before_block` exist.

**Python class.** `UniswapV3Pool` (`src/degenbot/uniswap/v3_liquidity_pool.py`, 1075 lines): `__init__` gains `self._py_pool`; `ConcentratedLiquidityStateManager[UniswapV3PoolState]` reads delegate to `self._py_pool`; `external_update` (Swap/Mint/Burn decoders) → `PyBot.update_v3_pool` + liquidity-update; `simulate_swap`/`calculate_tokens_*` → `self._py_pool.calculate_tokens_out`. Keep `PublisherMixin`/`PoolPickleMixin`/`UniswapV3PoolCalc`.

**Registries.** `ManagedPoolRegistry`/`PoolRegistry` store `UniswapV3Pool` companions.

**Tests.** V3 pool tests (calc outputs, Swap/Mint/Burn application, reorg restore); `test_py_bot.py` V3 tests.
