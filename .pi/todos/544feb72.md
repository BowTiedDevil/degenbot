COMPLETED. Changes:

uniswap_engine_pump.rs:
- Replaced once-at-startup `relevant_addrs` snapshot with per-block snapshot
- In `run_with_stream()`: removed the single `collect_relevant_addrs` call at startup
- Instead, take a fresh snapshot on each block header and on each timeout handler invocation
- This ensures newly-registered pools are immediately reflected in log filtering
- The lock is held only for O(pools) time (just reading HashMap keys), released before the O(n) log filtering
- The gap between snapshot and reacquire is harmless: Swap/Sync for newly-registered pools are reflected in registration state; Mint/Burn are caught by the sub-engine event buffer
