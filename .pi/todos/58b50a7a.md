## Resolution

Fixed V2-V4 encoder with multiple bugs:

1. **V4 output is native ETH (v4_output_is_native)**: Added `WETH_DEPOSIT(weth_out)` after V4_TAKE to wrap ETH→WETH, then `ERC20_TRANSFER(weth→v2)` to pay V2's flash debt. Without this, V4 takes native ETH to executor but V2 needs WETH.

2. **V2 callback ordering**: Moved `V4_UNLOCK` before `ERC20_TRANSFER(weth→v2)` in the callback. The executor has no WETH before V4 runs — V4 provides the tokens first, then the executor pays V2.

3. **Hardcoded `V4_TAKE(weth_idx)`**: Replaced with `V4_TAKE(output_idx, executor, weth_out)` using the correct V4 output currency index.

4. **Removed stray `V4_UNLOCK` after V2 swap**: V4_UNLOCK is now always inside V2's callback, never appended after the V2 swap.
