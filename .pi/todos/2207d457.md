## Command Stream Size Budget
The new contract limits command streams to 288 bytes. With the compact encoding (uint96 amounts, 2-byte fee), a typical 3-hop path fits in ~120-180 bytes. The sentinel optimization further reduces this. No path should exceed 288 bytes.
