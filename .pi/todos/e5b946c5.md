**Master: `TODO-215e9e66` (ADR-006).** Deps: slices 4 + 5. Addresses ADR-006 (Idea 1, coalesced drain trigger).

**Goal.** The drain-point solve tick. `SolveCoordinator` subscribes to `BlockPump`'s drain (empty log queue) + block-boundary events and asks each attached engine to solve its dirties per the **coalesced α policy** (the existing eager-processing invariant restated in bus vocabulary — no new solve debounce; today's existing 50ms send-result debounce stays unchanged). The engine takes its `Mutex` + a core `read()` guard to re-derive `IntHopState`/`IntV3TickRangeSequence` from current `BotState` and re-solve affected paths (lock order engine-then-core preserved).

**Rust work.**
- New `pub(crate) struct SolveCoordinator`: holds `engines: Vec<Arc<Mutex<dyn Engine>>>` (or a registered sink list), exposes `on_drain(&self, block, metadata)` — for each engine: `engine.lock().solve_dirty(block, metadata)` (the engine's existing solve path, which reads `BotState` under engine-then-core-read). Each engine owns its own dirty-set (seeded by slice-4 subscriber notifications), so no Bot-side dirty collection.
- Wire into `BlockPump`'s drain/block-boundary path (slice 5).
- The `SolvePolicy` enum (`Drain` default / `Eager` / `Block` / `Manual`) is **DEFERRED** (one consumer short of the seam bar; recorded in ADR-006) — do NOT build it here. Hardcode the `Drain` behavior; leave a comment marking where the policy would dispatch. Keep `SolvePolicy` distinct from the lifecycle `EnginePhase` state machine (orthogonal axes).
- Send-result path: `engine.lock().send_result_batch(metadata)` (debounced, unchanged from today's debounce) — the existing `tokio::mpsc` `ResultBatch` channel → Python stays.

**Tests.**
- Feed `LogDispatcher` N logs touching engine pools, assert they dirty N pool_ids; fire `on_drain` once; assert the engine solved once (coalesced, not N times) — proves eager-coalescing survives the rewrite.
- Lock-order test: `SolveCoordinator.on_drain` → engine `Mutex` then core `read()`, never core-then-engine.

**Acceptance.** `just test-all` green; coalesced drain solve works through the new topology; `SolvePolicy` enum explicitly deferred (commented, not built); the existing `DEBOUNCE_MS=50` send-result debounce unchanged. Eager-processing `{Eager Processing}` invariant in `rust/CONTEXT.md` holds under the new shape.
