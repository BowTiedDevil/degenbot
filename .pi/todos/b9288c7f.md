## Resolution

Fixed two bugs in the V4-V2 encoder:

1. **Native-ETH output path**: Replaced `ERC20_TRANSFER(weth→v2) + V2_SWAP_CALC` with `V2_SWAP_COMPACT(callback=ERC20_TRANSFER(weth→v2))`. The `V2_SWAP_CALC` approach doesn't work when the on-chain output differs from the solver's pre-computed amount. The `V2_SWAP_COMPACT` flash swap pattern (from the test) correctly handles this.

2. **Currency mismatch in settlement (root cause of ALL CurrencyNotSettled)**: All V4-V2 paths on mainnet have V4 pools with native ETH as currency0. The old code settled WETH into PM, but PM tracks native ETH as a separate currency. Fix: use `WETH_WITHDRAW(optimal_input) + V4_SETTLE_DELTA(native_idx)` to unwrap WETH→ETH before settling the native ETH delta.

### Results
- Before: 0 V4-V2 sim-ok
- After: 30 V4-V2 sim-ok, only 5 CurrencyNotSettled (residual, from token-specific issues)
- Remaining V4-V2 failures are token-level issues (Insufficient Balance, INSUFFICIENT_LIQUIDITY_MINTED, OVERFLOW) — not encoder bugs
