## Problem
V4-V4 different-currency paths (e.g., WETH→USDC→ETH) fail with `CurrencyNotSettled` because intermediate ERC-20 deltas are silently dropped.

## Resolution
The updated contract now uses `t_v4_deltas` — a full-currency delta ledger that tracks ALL currencies (not just ETH/WETH). Phase 3 settles all nonzero deltas for any currency. The `dynamic_amount` feature ensures intermediate deltas cancel exactly for V4-V4 paths.

Verified by contract test `test_v4_v4_usdc_intermediate_weth_eth` — 10/10 tests pass.
