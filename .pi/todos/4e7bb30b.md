## Resolution

Fixed V4-V3 encoder with the same WETH≠ETH currency mismatch pattern as V4-V2:

1. **Native-ETH output**: Kept `V4_TAKE(native→executor) + WETH_DEPOSIT + V3_SWAP_COMPACT(autopay) + V4_SETTLE_DELTA(input_idx)`. Removed spurious `V4_SETTLE_ALL`.

2. **ERC-20 output with native-ETH input**: Replaced explicit forward_data (V3 callback with sync+transfer+settle) with V3 auto-pay + `WETH_WITHDRAW + V4_SETTLE_DELTA(native_idx)`. This follows the `TestV4ToV3AutoPay` pattern but adds WETH_WITHDRAW when V4's input is native ETH.

3. **ERC-20 output with WETH input**: Uses `V4_SETTLE_DELTA(weth_idx)` after V3 auto-pay — matches the test exactly.
