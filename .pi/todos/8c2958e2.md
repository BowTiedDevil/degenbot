Structural refactoring in `rust/src/optimizers/uniswap_engine/py_binding.rs`.

`register_v3_pool` and `register_v4_pool` repeat the same structure: snapshot lookup, coverage tagging, three-stage buffer application, optional two-phase verification, and provider caching. The binary snapshot deserializers and streaming snapshot loaders are also near-mirror images.

Tasks:
- Extract a generic tick-snapshot store (`SnapshotStore<K>`) keyed by V3 address or V4 (manager, pool_id).
- Extract a shared registration helper that performs the three-stage snapshot/backfill/pump buffer application.
- Extract a shared verification helper parameterized by V3 vs V4 verifier functions.
- Keep Python-facing signatures unchanged.
- Run `just test-rust` and `just lint-rust`.
