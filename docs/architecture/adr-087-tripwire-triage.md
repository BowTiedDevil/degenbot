## The species test (ADR-087 D1)

One question decides every row:

> Does the artifact assert the **absence** of something deleted (**DELETE**), or does it
> exercise the **behavior** of something present (**KEEP**)?

Ties break toward KEEP: deletion is irreversible, relabeling is not.

## Class legend

| Class | Meaning | Action under D5 |
| --- | --- | --- |
| **DELETE** | A retirement tripwire: any test, gate, or prose prohibition whose purpose is keeping a deleted thing gone. Any surface — compiler-watched or compiler-blind, ADR-owned or orphan. Includes the 11 prose bans (vocabulary-bearing ones fold into a `GLOSSARY.md` `_Avoid_` line rather than vanishing outright). | Deleted in gate-verified batches; owning ADR gets a header note. |
| **KEEP-LIVE-BEHAVIOR** | An ordinary test of present-code behavior — including pointed-retirement-error paths (a `database upgrade` subcommand rendering its retirement line, a loader refusing a retired key). These were never tripwires (D1 clarification 1). | Kept as-is; no D2 relabel needed (it tests behavior, it does not watch a deleted thing). |
| **KEEP-RECLASSIFY** | A live-invariant gate watching **present** code — dependency edges, seam privacy, manifest wiring, env-read confinement, stub drift (D2). | Kept and relabeled with the D2 live-invariant label stating what present code it watches. |

## Evidence conventions

- `absent ⇒ DELETE`: the retired name/token is absent from live code everywhere, so the
  artifact is watching a dead thing.
- `present ⇒ KEEP`: the guarded token is live code, so the artifact is watching a
  present invariant.
- `behavior`: the artifact executes present code and asserts on its output/error — the
  D1 "tests of present code are not tripwires" clarification.
- `censusError`: the row does not exist at `file:line`, or the census labeled it as a
  tripwire when it is not one.
- `decomposes`: the census granularity merges tripwire assertions with live tests in one
  file/function; the deletion batch must cut only the absence-assertions named here.
