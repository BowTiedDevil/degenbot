Reused across lanes

  • One chain socket per host — WsIngestor fair-interleaves head + unfiltered logs and the Rust-side topic filter keeps both lanes on the same transport.
  • One hub per process — both the feed ring and the head watch became source registrations; drop-oldest + counter semantics preserved at name level (dropped_ring).
  • One world snapshot — boot load happens once; register/enable a strategy means handing it a handle.
  • One submission core — Bundle and Public routing are the same machinery with a target selection; the MEVBlocker URL merely puts the private endpoint ahead of the read provider in the public fan-out.
  • One sim stack — CacheDb + WriteCache + per-block StorageMemo own caching; the strategy never touches chain slots.
