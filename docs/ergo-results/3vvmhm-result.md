3VVMHM (C2.1, PR C2 commit 1): `profit_envelope.rs` splits into `kernel`/`derive`/`gate` (pure move).

`rust/crates/engine/degenbot-solvers/src/profit_envelope.rs` (4,876 lines, six fused concepts) is deleted and replaced by the directory `src/profit_envelope/` with `mod.rs` + `kernel.rs` (1,098 lines), `derive.rs` (946), `gate.rs` (967). `mod.rs` keeps the file-level doc comment, adds a short module-layout section, and re-exports the whole former public surface (`Line`, `HopMath`, `ClHop`, `PrefixCache`, `Envelope`, `GateSkipCause`, `GateDeps`, `GateCaptureCfg`, `GateStats`, `PathBoundLines`, `path_profit_bound*`, `path_output_bound_at`, plus the `pub(crate)` `path_bound_lines`, `path_bound_lines_with_stats`, `clamp_window_to_bound`), so `crate::profit_envelope::X` and `degenbot_solvers::profit_envelope::X` resolve unchanged.

Placement follows the task body: `kernel.rs` = the `Line`/I512 numeric kernel, exact hull composition (`compose_envelopes_exact`, `select_compose_pairs`, `hull_pieces`, `compose_boundary_reference`), `concave_max`, `clamp_window_to_bound`, `narrow`; `derive.rs` = per-hop derivation (`HopMath`, `ClHop`, `ClFan`, Möbius/CL tangent derivation, `hop_lines_and_cap[_cached]`, `classified_cl_rejection`, the degenerate-path capture `capture_degenerate_path` + `cl_seq_to_json`, the `PrefixCache` and its keys); `gate.rs` = `path_profit_bound*`, `Envelope`, `GateSkipCause`, `GateDeps`, `GateStats`/`record_gate`, `GateCaptureCfg`, `PathBoundLines`/`path_bound_lines*`, and the `prune` hull reduction whose counters are `GateStats`. Inline tests moved with the code they exercise into one `mod tests` per file.

No logic edits. The only non-move changes are the visibility/import adjustments the split requires: twelve top-level items plus `Line::{IDENTITY, compose, reduce, eval}` widened from module-private to `pub(crate)` for sibling use; explicit `use super::<module>::{...}` / `use crate::profit_envelope::<module>::{...}` imports replacing `use super::*`; the shared test shims (`prune`, `hop_lines_and_cap`) live in the owning module's `pub(crate) mod tests` and are imported by the others; and two `include_str!` fixture paths gained one `../` level (`../../tests/fixtures/gate_false_skip_93794.json`) because the file moved one directory deeper. Every test body is otherwise byte-identical (a line-multiset diff of the original against the union of the new files shows only those four expected items plus rustfmt line-wrapping of two signatures widened by `pub(crate)`).
