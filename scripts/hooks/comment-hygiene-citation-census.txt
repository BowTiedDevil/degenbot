# Comment-hygiene citation census — Detector 3 of scripts/hooks/comment-hygiene.sh
# Index: docs/gates.md section 1 "Comment hygiene".
#
# The anchored detector (Detector 1) and the bare-token ratchet (Detector 2)
# cannot see a citation spelled without an anchor word or an all-uppercase
# token: a lower-case hex tracker ID, a parenthesised work-item label, an
# epic/slice/phase label, pre-/post-epic narration. Detector 3 closes that gap
# the same ratchet way: every matched band must be accounted for here, so a NEW
# citation cannot land, and each sweep deletes the row it retired. The tree is
# swept: the only row left is a reviewed non-citation (below).
#
# Row format: "<repo-relative-path>:<matched band>", the band exactly as rg -o
# prints it with whitespace runs collapsed to one space (so the row survives a
# line reflow — it carries no line number). One row per site; alphabetical.
#
# The reconciliation is bidirectional and fails closed:
#   - a citation band with no row            -> fail (a new citation landed)
#   - a row with no citation band            -> fail (a swept row must go)
#   - the census file missing                -> fail (never pass over nothing)
#
# Regenerate after a sweep:
#   CCF=/dev/null scripts/hooks/comment-hygiene.sh 2>&1 |
#     sed -n 's/.* -> census row: //p' | sort -u
#
# Never list a tracker citation to silence it: restate the rule it introduced
# in prose (docs/comments.md) or delete the sentence. A row stays only when the
# match is NOT a work item, with the reason written above it.
#
# Known blind spots, by design:
#   - bare "phase <N>" is out of scope (algorithm phases, not plan phases): the
#     phase shape needs a letter+digit token, so the eager/boundary-tail phases
#     in tick_bitmap.rs, the pre-solve gap phases in instruments.rs and the GIL
#     phases in result_channel.rs are untouched.
#   - markdown is out of scope; docs are where tracker discussion lives.
#   - this hook and its two censuses are out of scope (they spell the shapes).
