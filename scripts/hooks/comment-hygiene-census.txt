# Comment-hygiene census — the bare-ID ratchet (scripts/hooks/comment-hygiene.sh)
#
# The anchored detector (ergo/epic/task/slice + RED/GREEN narration) cannot see
# bare six-char tracker tokens with no anchor word. Detector 2 of the hook
# closes that blind spot ratchet-style: it fails on any bare [A-Z0-9]{6} token
# in the scanned tree that is NOT accounted for here, so a new citation cannot
# land unnoticed. The whole tree is currently swept — this file is therefore
# lexicon-only, and it must stay that way.
#
# Lexicon: one bare token per line, sorted. Legit identifiers, English words,
# acronyms, EVM opcodes, and linter codes the bare-ID matcher would otherwise
# flag (its vocabulary: SIGINT, BEFORE, STATIC, OUTPUT, INPUT, STABLE, WETH,
# USDC). Extend ONLY for a real word, acronym, or domain identifier that the
# matcher trips on; a tracker citation must NEVER be added here — strip the
# citation from the code instead. A census line containing "/" would be read
# by the hook as a grandfathered path:token citation; that form exists only
# for a deliberate, explicitly reviewed exception and is currently unused.
#
# Pure-number tokens (tick values, block numbers) and hex-shaped tokens
# ([0-9A-F]{6} selector/byte data) are matcher exclusions in the hook, not
# census entries.
#
# ---- Lexicon (bare legit identifiers, sorted) ----
