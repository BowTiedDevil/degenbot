# Comment-hygiene census — the bare-ID ratchet (scripts/hooks/comment-hygiene.sh)
#
# The anchored detector (ergo/epic/task/slice + RED/GREEN narration) cannot see
# bare six-char tracker tokens with no anchor word. This census closes that
# blind spot ratchet-style: the gate fails on any bare [A-Z0-9]{6} token NOT
# accounted for here, so new citations cannot land while existing ones are
# grandfathered until swept. Sweeping is a follow-up task, never part of an
# unrelated change.
#
# The file has two sections:
#
# 1. Grandfathered citations — one "path:token" per line. The token is the bare
#    six-char token as it appears in that file; the scan scope (src/, tests/,
#    rust/crates with tests/benches/examples excluded) and the Rust
#    comment-line rule live in the hook.
#    SHRINK PROTOCOL — same voice as the waiver file: a census entry means
#    "this file still carries pre-rule citations"; it NEVER licenses new ones.
#    Remove the entry in the same commit that strips the citation from the
#    file, and never add an entry for a token that is not already in the file.
# 2. Lexicon — one bare token per line (no path): legit identifiers, English
#    words, acronyms, and linter codes the sweep commits classified as
#    non-citations (their vocabulary: SIGINT, BEFORE, STATIC, OUTPUT, INPUT,
#    STABLE, WETH, USDC, pure-number tokens, hex tokens). Extend ONLY for a
#    real word, acronym, or domain identifier; a tracker citation must never
#    be added here.
#
# Pure-number tokens (tick values, block numbers) and hex-shaped tokens
# ([0-9A-F]{6} selector/byte data) are matcher exclusions, not census entries;
# a deliberate hex-spelled citation (E2B542) is ratcheted by its citation
# entries below, which the matcher checks before the hex exclusion.
